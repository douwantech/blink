账号标签

每个账号自己的标签，独立保存；新增和关闭只影响该账号，会话名为 员工-项目（远端约定加 cc- 前缀）。上面那套全局公用标签不在这个列表里——它不落库到账号，是所有人登录时由服务端现算的。

公用标签

「公用」项目名单里的每个 员工×项目 就是一条全局标签。所有账号登录后默认都有这一套，不用逐个账号去建；改了项目名单，所有人下次同步就跟着变。未被标为「公用」的项目（如 main/blink）不在这里出现。
